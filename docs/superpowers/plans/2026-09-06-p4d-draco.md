## 0. 关键事实（执行者必读）

1. **cgltf draco 扩展结构**：`prim.has_draco_mesh_compression` /
   `prim.draco_mesh_compression.buffer_view` / `.attributes[]`；扩展 attributes
   的 JSON 值（draco unique_id）经 `CGLTF_PTRINDEX` 存进 `attr->data`（假指针），
   取回：`uint32_t uid = uint32_t(reinterpret_cast<uintptr_t>(attr.data));`
   `attr->name` = 语义串（"POSITION"/"TEXCOORD_0"...）。
2. **draco 1.5.x API**（头文件以 `_deps/draco-src/src/draco/...` 为准）：
   - 解码：`draco::DecoderBuffer buf(ptr, size); draco::Decoder dec;
     auto res = dec.DecodeMeshFromBuffer(buf);` → `res.ok()/res.value()`;
     `mesh.num_faces()/mesh.face(FaceIndex)`；`mesh.GetAttributeByUniqueId(uid)`；
     `attr->mapped_index(PointIndex(i))` → `AttributeValueIndex`；
     `attr->ConvertValue(avIndex, numComps, outFloatPtr)`（模板重载）。
   - 编码：`draco::Mesh` + `AddAttribute(GeometryAttribute, identity_mapping=true,
     numValues)` + `attr->SetAttributeValue(AVIndex, ptr)` + `SetFace` +
     `attr->set_unique_id(n)`；`draco::Encoder
     SetAttributeQuantization(Type, bits); EncodeMeshToBuffer(mesh, &ebuf)`。
3. **零回归硬约束**：无扩展资产路径仅多一次空遍历提前返回;Task 1 后全量
   249 用例必须通过。

`tests/common/draco_gen.cpp`（球体参数化同 primitives::makeSphere(0.5, 32, 16)
公式,自算避免引 core 依赖;draco Mesh 构造 → Encoder → glb 写盘）：

```cpp
#include "common/draco_gen.h"
#include "draco/compression/encode.h"
#include "draco/attributes/geometry_attribute.h"
#include "draco/core/encoder_buffer.h"
#include "draco/mesh/mesh.h"
#include <cmath>
#include <cstdio>
#include <cstring>
#include <filesystem>
#include <vector>

namespace rd::test {
namespace {
constexpr uint32_t kSeg = 32, kRings = 16;  // 与 makeSphere(0.5,32,16) 同参数化
}

void dracoSphereSource(std::vector<float>& pos, std::vector<float>& nrm,
                       std::vector<float>& uv, std::vector<uint16_t>& idx) {
  const float r = 0.5f;
  pos.clear(); nrm.clear(); uv.clear(); idx.clear();
  for (uint32_t y = 0; y <= kRings; ++y)
    for (uint32_t x = 0; x <= kSeg; ++x) {
      const float u = float(x) / float(kSeg), v = float(y) / float(kRings);
      const float theta = u * 2.0f * float(M_PI), phi = v * float(M_PI);
      const float dx = std::sin(phi) * std::cos(theta);
      const float dy = std::cos(phi);
      const float dz = std::sin(phi) * std::sin(theta);
      pos.insert(pos.end(), {r * dx, r * dy, r * dz});
      nrm.insert(nrm.end(), {dx, dy, dz});
      uv.insert(uv.end(), {u, v});
    }
  const uint32_t w = kSeg + 1;
  for (uint32_t y = 0; y < kRings; ++y)
    for (uint32_t x = 0; x < kSeg; ++x) {
      const uint16_t a = uint16_t(y * w + x), b = uint16_t(y * w + x + 1);
      const uint16_t c = uint16_t((y + 1) * w + x), d = uint16_t((y + 1) * w + x + 1);
      idx.insert(idx.end(), {a, c, b, b, c, d});
    }
}

std::string writeDracoSphere(const std::string& dirStr) {
  namespace fs = std::filesystem;
  const fs::path dir(dirStr);
  std::error_code ec;
  fs::create_directories(dir, ec);
  std::vector<float> pos, nrm, uv;
  std::vector<uint16_t> idx;
  dracoSphereSource(pos, nrm, uv, idx);
  const uint32_t vc = uint32_t(pos.size() / 3);
  const uint32_t tc = uint32_t(idx.size() / 3);
  // joints(u8 全 0=根骨)/weights(float (1,0,0,0))
  std::vector<uint8_t> joints(vc * 4, 0);
  std::vector<float> weights(vc * 4, 0.0f);
  for (uint32_t v = 0; v < vc; ++v) {
    weights[v * 4] = 1.0f;
  }

  draco::Mesh mesh;
  mesh.SetNumFaces(tc);
  for (uint32_t f = 0; f < tc; ++f) {
    mesh.SetFace(draco::FaceIndex(f),
                 draco::Face({draco::PointIndex(idx[f * 3]), draco::PointIndex(idx[f * 3 + 1]),
                              draco::PointIndex(idx[f * 3 + 2])}));
  }
  auto addAttr = [&](draco::GeometryAttribute::Type t, uint32_t comps,
                     draco::DataType dt, const void* data, size_t bytesPerVal,
                     uint32_t uniqueId) {
    draco::GeometryAttribute ga;
    ga.Init(t, nullptr, int(comps), dt, false, uint32_t(bytesPerVal), 0);
    const int ai = mesh.AddAttribute(ga, true, vc);
    mesh.attribute(ai)->set_unique_id(uniqueId);
    for (uint32_t v = 0; v < vc; ++v)
      mesh.attribute(ai)->SetAttributeValue(
          draco::AttributeValueIndex(v),
          static_cast<const uint8_t*>(data) + size_t(v) * bytesPerVal);
    return ai;
  };
  addAttr(draco::GeometryAttribute::POSITION, 3, draco::DT_FLOAT32, pos.data(), 12, 1);
  addAttr(draco::GeometryAttribute::NORMAL, 3, draco::DT_FLOAT32, nrm.data(), 12, 2);
  addAttr(draco::GeometryAttribute::TEX_COORD, 2, draco::DT_FLOAT32, uv.data(), 8, 3);
  addAttr(draco::GeometryAttribute::GENERIC, 4, draco::DT_UINT8, joints.data(), 4, 4);
  addAttr(draco::GeometryAttribute::GENERIC, 4, draco::DT_FLOAT32, weights.data(), 16, 5);

  draco::Encoder encoder;
  encoder.SetSpeedOptions(10, 10);                       // 确定性:最快=无预测歧义
  encoder.SetAttributeQuantization(draco::GeometryAttribute::POSITION, 14);
  draco::EncoderBuffer ebuf;
  if (!encoder.EncodeMeshToBuffer(mesh, &ebuf).ok()) return {};
  const std::vector<uint8_t> bin(static_cast<const uint8_t*>(ebuf.data()),
                                 static_cast<const uint8_t*>(ebuf.data()) + ebuf.size());

  // glb:JSON chunk + BIN chunk(仅 draco 流)
  char json[2048];
  const int jsonLen = std::snprintf(
      json, sizeof(json),
      R"({"asset":{"version":"2.0"},"scene":0,"scenes":[{"nodes":[0]}],"nodes":[{"mesh":0,"skin":0},)"
      R"({"children":[1]},{"translation":[0,0,0]}],)"
      R"("meshes":[{"primitives":[{"attributes":{"POSITION":0,"NORMAL":1,"TEXCOORD_0":2,)"
      R"("JOINTS_0":3,"WEIGHTS_0":4},"indices":5,"material":0,"extensions":)"
      R"({"KHR_draco_mesh_compression":{"bufferView":0,"attributes":)"
      R"({"POSITION":1,"NORMAL":2,"TEXCOORD_0":3,"JOINTS_0":4,"WEIGHTS_0":5}}}}]}],)"
      R"("materials":[{"pbrMetallicRoughness":{"baseColorFactor":[0.8,0.6,0.5,1]}}],)"
      R"("skins":[{"joints":[1]}],)"
      R"("extensionsUsed":["KHR_draco_mesh_compression"],)"
      R"("extensionsRequired":["KHR_draco_mesh_compression"],)"
      R"("buffers":[{"byteLength":%u}],)"
      R"("bufferViews":[{"buffer":0,"byteOffset":0,"byteLength":%u}],)"
      R"("accessors":[{"componentType":5126,"count":%u,"type":"VEC3"},)"
      R"({"componentType":5126,"count":%u,"type":"VEC3"},)"
      R"({"componentType":5126,"count":%u,"type":"VEC2"},)"
      R"({"componentType":5121,"count":%u,"type":"VEC4"},)"
      R"({"componentType":5126,"count":%u,"type":"VEC4"},)"
      R"({"componentType":5123,"count":%u,"type":"SCALAR","max":[0],"min":[0]}]})",
      uint32_t(bin.size()), uint32_t(bin.size()), vc, vc, vc, vc, vc, tc * 3);
  const int jsonPad = (4 - (jsonLen % 4)) % 4;
  const int binPad = (4 - (int(bin.size()) % 4)) % 4;
  const uint32_t total = 12 + uint32_t(8 + jsonLen + jsonPad) +
                         uint32_t(8 + bin.size() + binPad);
  const fs::path out = dir / "draco_sphere.glb";
  FILE* f = fopen(out.string().c_str(), "wb");
  if (!f) return {};
  auto w32 = [&](uint32_t v) { fwrite(&v, 4, 1, f); };
  w32(0x46546C67); w32(2); w32(total);
  w32(uint32_t(8 + jsonLen + jsonPad)); w32(0x4E4F534A);
  fwrite(json, 1, size_t(jsonLen), f);
  for (int i = 0; i < jsonPad; ++i) fputc(' ', f);
  w32(uint32_t(8 + bin.size() + binPad)); w32(0x004E4942);
  fwrite(bin.data(), 1, bin.size(), f);
  for (size_t i = 0; i < size_t(binPad); ++i) fputc(0, f);
  fclose(f);
  return out.string();
}

} // namespace rd::test
```

```cpp
#include "resource/draco_decode.h"
#include "draco/compression/decode.h"
#include "draco/core/decoder_buffer.h"
#include "draco/mesh/mesh.h"
#include "foundation/log.h"
#include <cstring>

namespace rd {
namespace {

/// 单 primitive 解码结果 → 连续 blob + accessor 链
struct DracoPrim {
  std::unique_ptr<uint8_t[]> blob;
  std::vector<cgltf_buffer> buffers;        // 1 个
  std::vector<cgltf_buffer_view> views;
  std::vector<cgltf_accessor> accessors;    // 与 views 对齐
};

uint32_t uidOf(const cgltf_attribute& a) {
  return uint32_t(reinterpret_cast<uintptr_t>(a.data));
}

/// 按 JSON accessor 的 componentType 落盘分量(dest 已按类型对齐)
void storeComponent(void* dst, cgltf_component_type ct, float v) {
  switch (ct) {
    case cgltf_component_type_r_8u: *static_cast<uint8_t*>(dst) = uint8_t(v); break;
    case cgltf_component_type_r_16u: *static_cast<uint16_t*>(dst) = uint16_t(v); break;
    case cgltf_component_type_r_32u: *static_cast<uint32_t*>(dst) = uint32_t(v); break;
    case cgltf_component_type_r_32f: *static_cast<float*>(dst) = v; break;
    default: *static_cast<float*>(dst) = v; break;  // 8/16 有符号不出现于当前语义
  }
}
uint32_t componentSize(cgltf_component_type ct) {
  switch (ct) {
    case cgltf_component_type_r_8:
    case cgltf_component_type_r_8u: return 1;
    case cgltf_component_type_r_16:
    case cgltf_component_type_r_16u: return 2;
    default: return 4;
  }
}
uint32_t typeComponents(cgltf_type t) {
  switch (t) {
    case cgltf_type_vec2: return 2;
    case cgltf_type_vec3: return 3;
    case cgltf_type_vec4:
    case cgltf_type_mat2: return 4;  // mat 特例不管(draco 语义不产 mat)
    default: return 1;
  }
}

/// 解码一个 primitive;失败返回 false(保持原样)
bool decodePrimitive(const cgltf_primitive& prim, DracoPrim& out) {
  const cgltf_draco_mesh_compression& ext = prim.draco_mesh_compression;
  const cgltf_buffer_view* bv = ext.buffer_view;
  const cgltf_buffer* buf = bv ? bv->buffer : nullptr;
  if (!bv || !buf || !buf->data) return false;
  const uint8_t* stream = static_cast<const uint8_t*>(buf->data) + bv->offset;

  draco::DecoderBuffer dbuf(stream, bv->size);
  draco::Decoder decoder;
  draco::StatusOr<std::unique_ptr<draco::Mesh>> res =
      decoder.DecodeMeshFromBuffer(dbuf);
  if (!res.ok()) return false;
  const draco::Mesh& mesh = *res.value();

  // 1) 索引:faces → JSON 声明 componentType
  const cgltf_accessor* idxJson = prim.indices;
  if (!idxJson || mesh.num_faces() == 0) return false;
  const uint32_t ic = idxJson->count;
  if (ic != mesh.num_faces() * 3) return false;  // 声明与解码不符 → 拒绝
  const uint32_t iSize = componentSize(idxJson->component_type);
  std::vector<size_t> offsets;    // 每合成 accessor 的 blob 偏移
  std::vector<const cgltf_accessor*> jsons;
  std::vector<const draco::PointAttribute*> attrs;
  offsets.push_back(0);
  jsons.push_back(idxJson);
  attrs.push_back(nullptr);       // 索引走 faces
  size_t blobSize = size_t(ic) * iSize;

  // 2) 属性:JSON 语义 → 扩展 unique_id → draco attribute
  for (cgltf_size a = 0; a < prim.attributes_count; ++a) {
    const cgltf_attribute& pa = prim.attributes[a];
    if (pa.type == cgltf_attribute_type_invalid || !pa.data) continue;
    const draco::PointAttribute* da = nullptr;
    for (cgltf_size e = 0; e < ext.attributes_count; ++e)
      if (ext.attributes[e].name && pa.name &&
          strcmp(ext.attributes[e].name, pa.name) == 0) {
        da = mesh.GetAttributeByUniqueId(uidOf(ext.attributes[e]));
        break;
      }
    if (!da) return false;  // 缺属性 → 整体拒绝(宽松:跳过会静默错形)
    const size_t sz = size_t(pa.data->count) * typeComponents(pa.data->type) *
                      componentSize(pa.data->component_type);
    blobSize = (blobSize + 3) & ~size_t(3);  // 4 对齐
    offsets.push_back(blobSize);
    jsons.push_back(pa.data);
    attrs.push_back(da);
    blobSize += sz;
  }
  if (blobSize == 0) return false;

  // 3) blob 落盘 + 链合成
  out.blob.reset(new uint8_t[blobSize]);
  std::memset(out.blob.get(), 0, blobSize);
  out.buffers.resize(1);
  out.buffers[0].data = out.blob.get();
  out.buffers[0].size = cgltf_size(blobSize);
  out.views.resize(jsons.size());
  out.accessors.resize(jsons.size());
  for (size_t k = 0; k < jsons.size(); ++k) {
    const cgltf_accessor* src = jsons[k];
    out.views[k].buffer = &out.buffers[0];
    out.views[k].offset = cgltf_size(offsets[k]);
    out.views[k].size = cgltf_size(src->count * typeComponents(src->type) *
                                   componentSize(src->component_type));
    out.views[k].stride = 0;  // 紧凑
    out.accessors[k] = *src;  // 复制 JSON 声明(count/type/component_type/min/max)
    out.accessors[k].buffer_view = &out.views[k];
    out.accessors[k].byte_offset = 0;
    out.accessors[k].is_sparse = cgltf_false;
  }

  // 索引写值(faces)
  uint8_t* base = out.blob.get();
  const uint32_t nComps = typeComponents(idxJson->type);
  for (uint32_t i = 0; i < ic; ++i) {
    const draco::Face& f = mesh.face(draco::FaceIndex(i / 3));
    const uint32_t v = f[i % 3].value();
    storeComponent(base + offsets[0] + size_t(i) * iSize, idxJson->component_type,
                   float(v));
  }
  (void)nComps;
  // 属性写值(mapped_index 逐点)
  for (size_t k = 1; k < jsons.size(); ++k) {
    const cgltf_accessor* src = jsons[k];
    const draco::PointAttribute* da = attrs[k];
    const uint32_t comps = typeComponents(src->type);
    const uint32_t cSize = componentSize(src->component_type);
    float tmp[4];
    for (cgltf_size v = 0; v < src->count; ++v) {
      const draco::AttributeValueIndex avi = da->mapped_index(draco::PointIndex(v));
      if (!da->ConvertValue(avi, int(comps), tmp)) {
        for (auto& t : tmp) t = 0.0f;  // 转换失败写 0(宽松)
      }
      for (uint32_t c = 0; c < comps; ++c)
        storeComponent(base + offsets[k] + (size_t(v) * comps + c) * cSize,
                       src->component_type, tmp[c]);
    }
  }
  return true;
}

} // namespace

size_t applyDracoDecoding(cgltf_data* data,
                          std::vector<std::unique_ptr<uint8_t[]>>& decodedStorage) {
  size_t decoded = 0;
  for (cgltf_size mi = 0; mi < data->meshes_count; ++mi) {
    cgltf_mesh& mesh = data->meshes[mi];
    for (cgltf_size pi = 0; pi < mesh.primitives_count; ++pi) {
      cgltf_primitive& prim = mesh.primitives[pi];
      if (!prim.has_draco_mesh_compression) continue;
      auto dp = std::make_unique<DracoPrim>();
      if (decodePrimitive(prim, *dp)) {
        // 改写指针(索引/属性)
        const size_t n = dp->accessors.size();
        prim.indices = &dp->accessors[0];
        for (cgltf_size a = 0; a < prim.attributes_count; ++a)
          for (size_t k = 1; k < n; ++k)  // 语义匹配的 JSON accessor 换合成版
            if (prim.attributes[a].data == jsonAccessorOf(prim, k))
              prim.attributes[a].data = &dp->accessors[k];
        decodedStorage.push_back(std::move(dp->blob));
        // DracoPrim 的 views/buffers/accessors 也须保活——storage 改持整个 DracoPrim
        ++decoded;
      } else {
        RD_LOGW("resource.draco", "primitive 解码失败,跳过(mesh %s)", mesh.name ?: "");
      }
    }
  }
  return decoded;
}

} // namespace rd
```

**实现修正(执行者按此落地,上面是语义骨架)**:
1. **保活**:storage 类型改为 `std::vector<std::unique_ptr<DracoPrim>>`(blob/
   buffers/views/accessors 整体保活),头文件签名同步——把 DracoPrim 移到
   `draco_decode.h` 或用前向声明 + `std::unique_ptr<void, ...>` 不便;最简:
   头文件导出 `struct DracoPrimBlock;`(完整定义在 .cpp,
   `std::vector<std::unique_ptr<DracoPrimBlock>>&` 前向声明可用)。
2. **jsonAccessorOf**:改写循环需要"扩展属性 k 对应哪个 prim.attributes 下标"。
   在 decodePrimitive 里直接返回映射最简——把改写也移进 decodePrimitive:
   ```cpp
   // decodePrimitive 尾部(合成完成后):
   prim.indices = &out.accessors[0];
   for (cgltf_size a = 0; a < prim.attributes_count; ++a)
     for (size_t k = 1; k < out.jsonToSynth.size(); ++k)  // 记录的 JSON→合成下标
       if (prim.attributes[a].data == out.jsonSrc[k])
         prim.attributes[a].data = &out.accessors[out.jsonToSynth[k]];
   ```
   即 DracoPrim 记 `std::vector<const cgltf_accessor*> jsonSrc`(对应 accessors
   下标 1..n),外层只做 storage 持有 + 计数。
3. `mesh.name ?: ""` 非标准 C++——`mesh.name ? mesh.name : ""`。
4. `cgltf_accessor` 复制时 `*src` 会拷 buffer_view/子结构指针——必须在拷贝后
   覆写 buffer_view/byte_offset(上文已做);`sparse` 子结构指针一并置空 ✓。

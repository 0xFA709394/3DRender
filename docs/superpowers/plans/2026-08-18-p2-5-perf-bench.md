`tools/perf_test/main.cpp` 完整实现:

```cpp
// ============================================================================
// perf_test:性能基准工具(host)。离屏 512×512,4 场景 × 双后端逐帧计时。
// 用法: perf_test [--backend metal|vulkan|all] [--frames N] [--scene name]
//                 [--json out.json] [--no-gate] [--update-baseline]
// 退出码: 0=成功(门槛通过或 --no-gate);1=失败;2=基线缺失(--update-baseline 生成)
// ============================================================================
#include <algorithm>
#include <chrono>
#include <cstdio>
#include <cstring>
#include <string>
#include <vector>
#include "common/image.h"
#include "common/shader_code.h"
#include "common/skinned_gen.h"
#include "renderer/renderer.h"
#include "resource/gltf_loader.h"
#include "resource/mesh_render_resource.h"
#include "scene/animator.h"
#include "scene/camera.h"
#include "rhi/rhi_device.h"
#include "rd_shader_dir.h"
#include <glm/glm.hpp>

namespace {
constexpr uint32_t kW = 512, kH = 512;
constexpr int kWarmup = 20;

struct SceneCtx {
  std::unique_ptr<rd::Device> device;
  rd::Renderer renderer;
  rd::TargetHandle target;
  std::vector<rd::MeshRenderResourcePtr> resources;  // 见下(类型修正:shared_ptr)
  ...
};
```

**实现要点(完整代码由此展开,无占位):**

```cpp
struct BenchResult {
  std::string scene;
  std::string backend;
  float avgMs = 0, p95Ms = 0, p99Ms = 0, fps = 0;
  int frames = 0;
};
```

1. **场景构建函数**:`buildScene(name, device, renderer)` 返回场景上下文:
   - `helmet_high` / `helmet_low`:loadGltf(DamagedHelmet)+ upload;setQuality(High/Low);
     High 加 1 方向光(setLights, color=3.0, direction 归一化 (0.5,0.8,0.3))+
     setLightFraming(boundingCenter, boundingRadius);Low 不加灯。
   - `skinned_anim`:writeSkinnedQuad(temp)+ loadGltf + upload + Animator bind/play(0)。
   - `items_64`:loadGltf(BoxTextured)+ upload;提交时 8×8 网格(world 平移
     (i%8-3.5)*1.5, (i/8-3.5)*1.5, 0);相机拉远 (0,0,8)。
2. **渲染循环**:`benchScene(ctx, frames)`:
   ```cpp
   std::vector<float> times;
   for (int f = 0; f < warmup + frames; ++f) {
     const float dt = 1.0f / 60.0f;  // 固定 dt(动画确定性)
     auto t0 = std::chrono::steady_clock::now();
     device->beginFrame();
     renderer.beginScene(cam, {0.05f, 0.05f, 0.06f, 1.0f});
     // 场景提交:skinned 走 animator.update(dt)+submit(palette);
     // items_64 循环 submit 64 项;helmet 单项 submit(identity world)
     auto* cmd = device->acquireCommandBuffer();
     renderer.endScene(cmd, target);
     device->submit(cmd);
     device->waitIdle();
     device->endFrame();
     auto t1 = std::chrono::steady_clock::now();
     if (f >= warmup) times.push_back(std::chrono::duration<float, std::milli>(t1 - t0).count());
   }
   // 统计:avg/p95/p99/fps
   std::sort(times.begin(), times.end());
   ```
3. **main 流程**:解析参数 → 按 backend 集合(metal/vulkan/all)× 场景集合(4 或 --scene 单选)
   逐 bench → 打印表格 → JSON 输出 → 门槛判定(见 Task 2)。
4. **shader 加载**:同 render_test(loadShaderCode + 全 14 个 shader 名,RendererShaderDesc 聚合)。
5. **退出码**:全部场景完成且门槛通过(或 --no-gate)→ 0;门槛失败 → 1;初始化失败 → 1。
6. 打印格式(冒烟测试 grep 用):
   ```
   [bench] helmet_high   metal  avg=2.34ms p95=2.51ms p99=2.60ms fps=427
   ```

### Task 2: 基线 JSON + 软门槛

**Files:**
- Modify: `tools/perf_test/main.cpp`(基线读写/门槛判定)
- Create: `tests/perf/baseline.json`(本机生成入库)

- [ ] **Step 1: 基线格式与读写**

格式(自解析,~60 行手写 JSON 读写;仅支持本结构):

```json
{
  "helmet_high": {"metal": 2.34, "vulkan": 2.51},
  "helmet_low": {"metal": 1.10, "vulkan": 1.20},
  "skinned_anim": {"metal": 0.80, "vulkan": 0.85},
  "items_64": {"metal": 3.20, "vulkan": 3.40}
}
```

- 读取:基线文件路径 `RD_PERF_BASELINE` 环境变量,缺省
  `<源码树>/tests/perf/baseline.json`(经 CMake 定义 `RD_PERF_BASELINE_PATH` 传入:
  `target_compile_definitions(perf_test PRIVATE RD_PERF_BASELINE_PATH="${CMAKE_SOURCE_DIR}/tests/perf/baseline.json")`)。
- 解析:逐行扫描 `"scene"` 与 `"backend": number`(场景名/后端名固定集合,逐字匹配;
  不写通用 JSON 解析器)。
- `--update-baseline`:按本次结果重写基线文件(格式化输出,两空格缩进)。
- 门槛:每场景 `avg > baseline × 1.5` → FAIL 打印 `[gate] FAIL <scene> <backend> avg=.. baseline=..`;
  基线缺场景 → 打印 `[gate] SKIP(基线无此场景)` 不算失败。

- [ ] **Step 2: 生成基线 + 门槛验证**

Run: `./build/tools/perf_test/perf_test --backend all --update-baseline`
(生成/更新 tests/perf/baseline.json;**核对数值合理**——helmet_high 应明显慢于 helmet_low)
Run: `./build/tools/perf_test/perf_test --backend all`(门槛通过,退出 0)
Run: 手动把基线某值改小 10× 跑一次 → 该场景 FAIL 退出 1 → 恢复。
